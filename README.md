# Travel Planner

Full-stack travel planning application built with:

- Spring Boot
- PostgreSQL
- Docker
- Angular
- JWT Authentication

## Features

- User authentication
- Travel management
- Destinations
- Accommodation
- Activities
- Transport management

## Project Structure

/backend -> Spring Boot API
/frontend -> Angular app

## Tech Stack

Backend:
- Java 21
- Spring Boot 3
- PostgreSQL
- Spring Security
- JWT

Frontend:
- Angular 21
- TypeScript
- Tailwind (future)
